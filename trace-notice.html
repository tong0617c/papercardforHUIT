5、iPhone 用户必读：把本站「添加到主屏幕」再用（数据会一直被清）

iPhone 上「数据总是丢」多半不是网站坏了，是系统在清网页数据：①Safari 会在连续 7 天没打开本站后自动清空它的全部本地数据（Apple 的隐私策略 ITP，任何网站都躲不过）；②手机存储紧张、清理软件一键优化、无痕模式、系统升级、换机换浏览器时，也会把网页数据一起清掉。

把本站「添加到主屏幕」、之后从桌面图标打开，能明显改善这一点：主屏幕应用不计入那条 7 天规则，也不跟一堆标签页抢内存（无浏览器栏、更接近 App 的用法）。做法：用 Safari 打开本站 → 点底部中间的「分享」按钮（方框加箭头）→「添加到主屏幕」→ 再从手机桌面点新图标进入。

注意：主屏幕应用与 Safari 是两套独立存储，切过去等于换个地方存数据。请按顺序做：①先在 Safari 里 设置 → 通用 →「导出数据」导一份完整备份；②再「添加到主屏幕」；③从桌面图标打开，走 设置 → 通用 →「导入数据」恢复；④以后平时都从桌面图标用。

不管哪种手机、哪种浏览器，本地数据都可能被系统清掉：定期「导出数据」备份才是唯一可靠的防线（导出的文件别只留一个地方：文件 App / 云盘 / 微信收藏各留一份）。

iPhone 上用 Edge / Chrome 的「添加到主屏幕」只会生成一个快捷方式，打开仍是带工具栏的浏览器页面，拿不到独立应用与那条 7 天豁免——请用 Safari 添加。

不只 iPhone：建议都把本站「添加到主屏幕」用（iPhone：Safari 底部分享按钮 → 添加到主屏幕，之后从桌面图标打开）——浏览器里直接打开的网页是手机清数据时的头号受害者，数据说没就没；从桌面图标用耐用得多。

再配合三点：①给手机留几个 GB 空闲存储；②别点 Safari 的「清除历史记录与网站数据」；③导出的备份文件存多处（微信/云盘/文件各留一份）。

详见 设置 → 关于 →「减少数据被手机清掉的几率」。

滑杆按「哪一页生效」分三组：两个页面通用的位置轴（顶部 / 底部 / 页面高度 / 整体位移 / 左右安全边）、只影响桌面页的「桌面图标区」、只影响聊天与设置里正文文字的「文字大小」；哪一组标着「你正在这一页」，拖那一组就对了。

用法：拖动滑杆边看边调、当场生效，双击滑杆回默认 0；面板挡住画面时按住标题行上下拖即可把它挪开，点「收起」变一枚小胶囊（点一下展开、也能拖走让位）；「全部恢复默认」一键归零；每台设备各自调、互不影响、不随联系人走。

建议先跑 设置 → 信息诊断 →「屏幕适配诊断」 看差多少像素，再来填对应偏移；聊天页内还可配合聊天设置→美化 的「顶栏/底栏位置」滑杆单独微调。

10、关于 TA 发消息太多（「回复条数」为什么管不住，以及新增的总量限流）

「回复条数最少/最多」＝你每发 1 条消息，TA 跟着回你几条，它只管这一件事，不是 TA 一天最多发几条。所以把它调成 1~2 之后，你还是可能收到很多条。

这几类不占「回复条数」的名额、会额外多发：词典拼字的「多回复逐卡连发」（默认不受条数限制）、撤回后补发、TA 的心情分享、红包/心意币/听歌邀请、TA 主动发送的消息（连发几条由「主动发送 → 发送条数」单独控制）。位置都在 聊天 → 更多 → 回复设置 → 聊天 →「回复与主动」。

「总量限流」（同面板下方，默认关闭）：打开后，任意「限流窗口」这段时间里 TA 最多发「窗口内最多条数」条，超出的直接不再发出，窗口滑过去自动恢复。上面那些额外多发的类型在这里全部一起计数、一起拦——已读回执、你当刻操作引发的记录（决定结果、游戏战绩、存钱罐结算、红包领取退回）、TA 在身边的换位播报（自动换位、【感知一下】催的那一发与你手动发的位置卡）不占额度也不会被拦；额度满时你刚说的那句话仍保底换来 1 条回应，不会只剩一个「已读」。两处例外请知悉：限流只管你当前打开的这个联系人（其他桌面的 TA 走跨桌面补投，不占这份额度）；经期关心、音乐互动的系统台词照常计入额度、也会被拦。

怎么配：嫌刷屏就开限流、窗口 5 分钟／上限 15 条起步（还是多就把上限往下调、窗口往上调）；只想让每句话的回应变短，就把「回复条数」两项都调成 1 并关掉「多字卡回复」。别把窗口拉到 60 分钟又把上限压到 1 条＝一小时只回你一句。限流按联系人独立生效，改动即时保存。

12、关于后台通知横幅的「N 条新消息」、点进去找不到东西、以及收藏变少（iPhone 主屏幕模式报障）

横幅改口了：以前那句「你不在的时候收到 N 条新消息」把查岗、贴贴/头像申请、来信、朋友圈动态、来电全算了进去，于是出现「提示有 2 条、点进去一条也没有」。现在按类别分开报，例如「你不在的时候收到 1 条新消息 · 1 次查岗 · 1 封来信」——只有真进了聊天的才叫「新消息」，没归到类别的只写「提醒」。

点通知会把你带到这条事件真正所在的地方：先切到它归属的那个联系人桌面，来信进信箱、其余进聊天；如果点的时候页面已被系统回收，重开后也会补跳一次（只认 3 分钟内的点击）。跨桌面查岗、贴贴申请落的是那个联系人自己的桌面，以前一律停在当前桌面的聊天页，所以「点进去什么都没有」。

收藏少掉的那批：这台机器的浏览器本地存储已写满到每一次写入都失败（诊断单上那句「写入失败(QuotaExceededError)」），于是屏幕上看到的是「最后一次写得进去的旧账」，而库里那本更新的反被遮住。现在只要这一层写不进去，旧账整场都不再充当最新，一律以库为准；顺带把占着配额、库里已有副本的历史残留从这一层请出去腾位置。重开一次，收藏应当回到库里那一本；若在变少之后又做过删除/整理，库里可能已被旧账顶掉，那种情况需要从备份找回。

13、关于「在后台放音乐，进本站突然变响、退出来又变轻」（后台保活不再占用手机音频通道）

成因：「后台保活」靠一条近乎无声的音频一直循环播放，让系统别把本页冻结，TA 的消息才照常进来。而这条在系统眼里＝「本站正在放媒体」＝占住了手机音频通道，你另一个 App 的音乐于是被强制压低。前一版为了治「站内一直有嘟嘟声」，把这条音频在前台压成 0、切到后台才恢复音量——于是每次切进切出都在改「本站到底算不算在放媒体」：进本站＝系统收走我们的占用，你的音乐恢复原音量（突然变响）；退出去＝我们又占上，你的音乐再被压低（又变轻）。这是音频通道的性质，不是某一款机型的毛病，各家认音频焦点的浏览器都一样。

现在的做法：那段近无声音频默认改走「站内音效」那条通道（设置 → 系统 新增一档「保活不抢其他 App 的声音」，默认开启）。页面照样持续出声、系统照样不冻结本页，但不再向手机声明「本站正在放媒体」——你在别的 App 听歌 / 看视频时不会被本站压低音量，切进切出也不再忽响忽轻。代价说清楚：通知栏那条「Mochi 后台保活」的媒体横幅不再出现，因为那条横幅本身就是那次音频通道的占用。

万一因此收不到后台消息：个别浏览器只认那条媒体横幅给的豁免。把 设置 → 系统 →「保活不抢其他 App 的声音」关掉就回到老路（有横幅、会占用音频通道），当场生效、不用等改版。上传了自定义保活音频（白噪音 / 助眠声）时这一档不参与——那是你要出声放的东西，照旧走媒体通道。想知道此刻走的是哪条：设置 → 查看诊断 →【保活现场】里的「锚=」那一格（媒体元素(占媒体通道) / WebAudio(不占媒体通道)）。

14、关于后台通知相关设置（怎么开、收不到怎么办）

三个开关都在 设置 → 系统：「后台通知」＝页面在后台时 TA 发消息弹系统通知（打开它会自动把「后台保活」一起打开，保活是通知的前提）；「通知逐条弹（关闭去重）」＝默认关闭（连发内容相同或近期弹过的消息只弹一条），打开后联系人每条消息都单独弹（字卡重复率高时会连环弹同句，按需开）；「后台保活」＝让页面在后台继续运行。

怎么确认通了：点「后台通知」行右边的「测试」——当场体检（开关 / 通知权限 / 后台保活与锚点 / 后台服务通道 / 历史冻结与断流取证）并真发一条通知、回读系统通知队列，卡在哪一环直接写在结果里；结果里还有第二段可测「后台阶段」。

收不到①·浏览器权限：地址栏左侧图标 → 权限 → 通知 → 允许；若列表里没有本站、或授权框从不出现（浏览器会把反复弹过授权框的站自动挡掉）→ Chrome ⋮ → 设置 → 网站设置 → 通知 →「添加网站例外」→ 输入本站网址。若你是从桌面图标（已安装应用）打开的，通知权限由应用自己管理、Chrome 网站设置里不显示本站属正常：长按图标卸载后重新「添加到主屏幕」，安装时允许通知即可重置。

收不到②·页面在后台被冻结或回收：保活靠页面在后台运行，系统省电/内存策略会把挂久的页面冻结甚至丢弃（Chrome「内存节省程序」约 30 分钟，手机内存紧张时更快），别的 App 刷视频/听音乐也会占用音频通道把保活截断——表现就是「弹一下就停了」。恢复：彻底关闭网页重新打开，再把「后台保活」「后台通知」重新打开；并把 Chrome 加入「始终保持活动」、省电策略设「无限制」，到 设置 → 工具 → 查看存储 清掉最占地方的数据（页越轻越不容易被丢）。

收不到③·设计内不弹：你正在前台看着聊天时不弹（聊天里直接可见）；切后台头 15 秒内的旧内容不弹（防刚看完的又弹一遍，打开「通知逐条弹」后此项不再拦）；跨桌面补投递的历史旧消息不弹。

收不到④·手机开了勿扰/免打扰：安卓的「勿扰/免打扰」、iPhone 的「专注模式」（勿扰·睡眠·驾驶·工作）会把所有应用的通知静默收进通知栏——屏幕上方不弹横幅，而网页读不到这个状态，所以会出现「测试体检全绿、通知真发出去了，屏幕上却什么都没有」。一步自查：下拉通知栏看那条测试通知在不在，在＝被系统压住，不是链路坏了——去系统设置关掉勿扰，或在勿扰设置里把本浏览器（或桌面上的 Mochi）加进「允许的应用/例外」。同一族还有：通知被长按成「静默/减少干扰」、浏览器「网站通知」那一类单独关掉、锁屏设成隐藏通知内容、iPhone 开过「定时推送摘要」（通知攒到点才出现）；电脑端＝Windows「请勿打扰/专注助手」与 macOS「专注模式」。另外开着本站自己的「夜间免打扰模式」（原「夜间模式」）时 22:00–7:00 TA 不主动发消息，后半夜本来就没有可弹的内容——本站那两个档管「有没有消息可弹」，手机系统勿扰管「有消息也弹不出来」。

换浏览器 / 换网址要重新允许：通知权限按「浏览器 + 网址」记，Chrome 与 Edge 各自独立；同一台手机换了浏览器，按上面「收不到①」重做一遍即可。
